# Ashraf Fathy — Portfolio

A responsive personal portfolio built with HTML, CSS, and Bootstrap.

## Run locally
1. Download or extract the project folder.
2. Open `index.html` in your browser.
3. An internet connection is needed to load Bootstrap and Google Fonts from their CDNs.

## Customize
- Update your bio and skill descriptions in `index.html`.
- Social links and email are in the hero and contact sections.
- Colors and layout styles are in `style.css`.

## Publish on GitHub
1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, and `README.md`.
3. To publish it as a live website, open the repository's **Settings → Pages**, choose the main branch and root folder, then save.
